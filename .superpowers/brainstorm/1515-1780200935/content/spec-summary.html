1. 要解决的问题

  • 后端有 Category.budgetLimit + API 返回 budgets，但仪表盘完全不显示
  • 设置页分类图标还在用 emoji，与全站 Lucide 化割裂

2. 文件变更

+ 新增 3 个文件

  • src/components/IconProvider.tsx — 图标主题 Context + Hook
  • src/lib/icon-themes.ts — 3 套图标映射表
✎ 修改 7 个文件
  • dashboard/page.tsx — 嵌入 BudgetOverview
  • api/dashboard/route.ts — 补 lastMonthSpent + allExpenseCategories
  • settings/page.tsx — 图标切换 UI + highlight 跳转
  • layout.tsx — 包裹 IconProvider
  • icon-map.tsx — 重写为 useIconTheme() 工厂
  • globals.css — 环动画 + 横幅动画
  • page.tsx — 首页图标迁移

3. 组件结构

<IconProvider>
  <DashboardPage>
    <StatCard /> ×3
    <BudgetOverview> ← 新增
      <BudgetAlertBanner /> ← 可关闭横幅
      <TotalBudgetRing /> ← 总环
      <CategoryRingCard /> ×N ← 分类环+文字
    </BudgetOverview>
    <CalendarView />
    <TrendChart />
  </DashboardPage>
</IconProvider>

4. 四个核心子组件

BudgetAlertBanner 有分类 ≥80% 预算时出现，✕ 关闭后当天不打扰
TotalBudgetRing 80px SVG 环 + 总金额文字 + 剩余天数
CategoryRingCard 40px 环 + 图标 + 已花/预算 + "剩/超"提示 + 月对比
无预算分类 灰色环 + 已花金额 + 点击跳设置页

5. 图标主题系统

三种主题：Lucide 线性 | Emoji | 色块图标

切换方式：设置页 → 点按钮 → 全站实时生效

存储：localStorage，刷新不丢

扩展：加新主题只改 icon-themes.ts 一个文件

14 个语义 key：food, transport, entertainment, shopping, housing, communication, medical, education, gift, pet, travel, beauty, digital, other

6. 预算状态规则

条件环颜色卡片边框文字
< 80% #2ea87a #e8f5ee 剩 ¥xxx
80-100% #f59e0b #fef3e0 剩 ¥xxx
≥ 100% #e25c3b #fde1d5 超 ¥xxx + 角标

7. API 改动

GET /api/dashboard 新增两个字段：

  • budgets[].lastMonthSpent — 上月同一分类支出（自然月）
  • allExpenseCategories — 所有支出分类，前端用来找"未设预算"的

8. YAGNI 边界（本次不做）

  • ❌ 预算历史趋势图
  • ❌ 预算设置向导
  • ❌ 推送通知
  • ❌ 收入预算（仅支出）
