三种改进方案，你更喜欢哪个方向？

点击卡片选择你喜欢的风格方向（可以多选）

A

深色自绘标题栏

隐藏 Windows 原生标题栏，自己画一个深色顶栏。像 VS Code / Notion 那样，窗口控件和 app 融为一体。

参考: VS Code, Figma
B

暖色自绘标题栏

同样隐藏原生标题栏，但用你的 app 暖色调（#faf7f2 纸色 / #f59e0b 琥珀），和内容区无缝衔接。

参考: 梧桐记账、随手记
C

保留原生框架 + 换颜色

保留 Windows 原生标题栏（拖拽、对齐、贴靠都正常），只把标题栏背景色换成琥珀色，低成本改善。

参考: Windows 11 设置、计算器
