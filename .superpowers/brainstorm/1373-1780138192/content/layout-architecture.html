布局架构 — 文件改动清单

核心思路：layout.tsx 用条件渲染区分首页/内页，LeftRail 只在非首页显示

组件树（桌面端）

RootLayout
├─ / (首页) → 无 LeftRail，全屏 Hub
├─ /dashboard
├─ /transactions
├─ /reports
├─ /recurring
└─ /settings
└─ 以上 5 页统一包裹：
   LeftRail (64px) + 内容区 flex:1

文件变更

文件 操作 说明
src/components/LeftRail.tsx 新建 64px 导航组件，接收 currentPath prop，高亮当前页
src/components/MobileTabBar.tsx 新建 底部 TabBar 组件，<768px 时替代 LeftRail
src/app/layout.tsx 修改 条件渲染：首页无左轨，内页 flex row(LeftRail + 内容)
src/components/TopBar.tsx 删除 不再需要返回箭头，左轨已提供导航
src/app/*/page.tsx (5个内页) 修改 移除 TopBar 引入，标题内嵌到页面内容顶部

关键实现细节

layout.tsx 条件逻辑

  • 用 usePathname() 判断是否首页
  • pathname === '/' → 居中全屏（现有行为）
  • pathname !== '/' → flex row: LeftRail + 内容
  • LeftRail 本身也是 client component（需要 usePathname 高亮当前页）

TopBar 替代方案

  • 内页标题从 TopBar 移到页面内容区顶部（h2 标签）
  • 左轨已标示当前所在页面，标题字的导航功能由左轨接管
  • 设置页无需特殊处理——LeftRail 底部 ⚙️ 即入口
